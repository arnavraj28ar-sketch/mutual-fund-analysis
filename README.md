# Mutual Fund Analysis

## About the Project

This project is based on mutual fund data analysis. The main purpose is to understand fund performance, returns, fund size, expense ratio, SIP and AMC-wise information.

Python and Pandas were used for data cleaning, data processing and analysis. Power BI was used to analyze the data and present the findings through interactive visuals.

## Tools Used

- Python
- Pandas
- NumPy
- Excel
- Power BI

## Analysis Performed

- Data cleaning and preprocessing
- Analysis of 1-year, 3-year and 5-year returns
- AMC-wise fund comparison
- Fund size and AUM analysis
- Expense ratio analysis
- SIP and minimum investment analysis
- Category and sub-category analysis

## Dashboard Pages

1. Mutual Fund Overview
2. Fund Analysis
3. Key Insights

## Key Insights

The project provides insights into mutual fund returns, fund size, AMC performance, expense ratios and investment requirements.

## Project Outcome

This project helped me understand the complete process of working with real-world data, from cleaning and analysis using Python and Pandas to visualization and insights using Power BI.
